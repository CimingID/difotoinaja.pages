Kebijakan Privasi — DiFotoinAja

Berlaku sejak: 11 Oktober 2026

DiFotoinAja adalah aplikasi photobooth yang dijalankan oleh operator pada perangkat miliknya sendiri. Kebijakan ini menjelaskan bagaimana data ditangani.

Data yang diproses

  • Foto sesi disimpan secara lokal di perangkat operator (tablet/PC).
  • Jika fitur galeri online diaktifkan, foto diunggah ke Google Drive milik akun operator (bukan server pihak ketiga milik pengembang) dan dibagikan lewat tautan kepada tamu yang bersangkutan.
  • Aplikasi tidak mengumpulkan data pribadi tamu, tidak memakai analytics, dan tidak mengirim data ke pihak ketiga.

Penggunaan Google Drive API

Aplikasi menggunakan Google Drive API dengan izin terbatas (drive.file): hanya file yang dibuat sendiri oleh aplikasi yang dapat diakses. Penggunaan data yang diperoleh dari API Google mematuhi Google API Services User Data Policy, termasuk persyaratan Limited Use.

Penghapusan data

Operator dapat menghapus foto kapan saja dari perangkat maupun dari Google Drive miliknya. Permintaan terkait data dapat dikirim ke kontak di bawah.
